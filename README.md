# El-impacto-de-la-adiccion-a-las-redes-sociales-en-el-rendimiento-academico-de-los-estudiantes
A pesar de la creciente evidencia que correlaciona la adicción a las redes sociales con un bajo rendimiento académico, la relación exacta sigue siendo compleja y no lineal.
Este proyecto tiene como objetivo desarrollar y validar modelos predictivos de clasificación capaces de anticipar el impacto negativo de la adicción a las redes sociales en el desempeño académico de los estudiantes. Para ello, se consideran múltiples variables, incluyendo el tiempo de uso, el nivel de adicción, las plataformas más utilizadas, la salud mental y los conflictos derivados de este uso.En este repositorio se realiza un análisis 

completo de datos: carga, exploración, preprocesamiento y evaluación de modelos de Regresión Logística, Árbol de Decisión y Naive Bayes.
